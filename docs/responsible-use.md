# 项目定位与使用说明

Muse2API 是社区独立维护的 HTTP 协议适配工具，主要面向个人学习、协议研究和本人创作工作流：将已有且获准使用的 Muse 会话接到本机或自己的服务器，再接入自己的客户端与 Skill。模型和生成服务由 Muse 上游提供，本项目负责接口、配置与操作流程。

感谢 Meta 团队在 Muse 产品、模型和开发者生态上的投入。建议优先使用官方网页、App 和适用的官方开发者路径，支持官方产品的持续建设。官方开放某套 SDK，不代表所有网页协议适配方式都已获许可；本项目的浏览器会话交接与官方 Gadget SDK 配对是不同路线。

## 尊重账号权益和服务限制

只在本人账号或已取得必要授权的范围内使用，并核对适用于自己账号、地区和使用方式的最新官方条款。网页登录成功、持有本实例 API Key 或技术调用成功，都不自动授予额外的自动化、账号共享、对外服务或转售权限。

## 个人部署与对外服务

本仓库默认是一份会话、一个上游配置的单用户实例，个人部署应保管好自己的密钥和会话，不公开管理端口或将凭据放入前端。不要让未获授权的人使用账号，也不要未经许可收集他人的输入、输出或登录资料。

Sub2API / New API、自有域名和网站后端的文档描述的是技术接入方式，不构成 Meta 对多人共享、商业运营或权益再分发的许可。计划对外服务前，应先核实上游授权、适用条款和数据归属；本项目不承诺商业服务可用性或服务等级。
