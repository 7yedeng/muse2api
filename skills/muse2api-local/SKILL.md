# Muse2API 本机维护

使用用户指定的 Muse2API 仓库和自己的账号。先读仓库 README 与本 Skill 的 [本机操作参考](references/local-operations.md)，核对当前脚本、版本和端口；不要寻找原维护者的服务、Key 或服务器配置。

需求明确时完成常规构建、全新配置生成、启动和只读状态检查。已有私密配置不覆盖；只关闭本次启动的进程。`run.py --check` 与 `/health` 不能证明上游推理可用。

浏览器授权由用户在 Chrome/Edge 普通窗口正常登录后，通过本项目扩展明确点击完成。代理不得读取 Cookie、Profile、storage state 或密码，不将浏览器控制工具变成会话导出器；也不把官方 Gadget 配对写成本项目已支持的网页登录流程。

管理端口仅 loopback；服务器管理通过用户已授权的 SSH-L，不能发布管理路由或为解决连接问题开放整个管理端口。API Key、AES 密钥和会话不进入聊天、命令参数、日志、Git 或 Skill。

状态分别验收：进程可访问、会话 ready、加密保存、重启恢复、明确授权的一次实际推理。用户明确要求生成某个作品即授权该次创建，不重复询问；仅安装维护不授权顺便生成。图片／视频保留 request-id，未知送达不自动重发。业务调用的回执、查询和下载使用 `muse2api-client` Skill 或仓库客户端，不把安装完成当作生成验收。
