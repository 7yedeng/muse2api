# 本机操作参考

## 定位与配置

仅在用户指定的仓库中查 README、`go.mod`、`scripts/`、`browser-extension/` 与 `deploy/`。若未给仓库位置，询问所需位置或按用户明确授权克隆公开仓库；不要扫描整个用户目录。

仓库提供：

```sh
python scripts/init_config.py
python scripts/run.py --check
python scripts/run.py
python scripts/admin.py status
python scripts/admin.py pair-code
```

Python 为 3.10+，Go 最低版本看当前 `go.mod`。生成器拒绝覆盖已有 `.env`，启动器只做配置加载、构建和启动，不自动调用上游生成。`.env`、运行目录及其密文必须排除公开发布。不要输出配置值来“确认已配置”；优先使用 `--check` 和脱敏状态。

如果由代理启动进程，保留本次进程句柄。Windows 后台启动使用当前工具支持的隐藏窗口方式；停止仅作用于该句柄，不批量结束系统 Python/Go 进程。

## 显式浏览器授权

默认业务地址 `127.0.0.1:18688`，管理地址 `127.0.0.1:18689`。用户在精确的 `https://muse.ai` 普通窗口正常登录并加载扩展，然后取得一次性码、填写管理端口、点击授权。扩展是唯一承担显式会话交接的产品组件，代理不读取它收集或发送的原文。

一次性码有效 120 秒且单次消费。授权失败先检查官网账号能否使用、当前浏览器账号、端口和码是否对应同一实例。不要通过导出整个 Profile、关闭浏览器安全设置或不停重试来解决。

## 服务器与恢复

只有用户已授权管理其服务器时才操作 SSH。隧道示例：

```sh
ssh -N -L 18689:127.0.0.1:18689 user@your-server
```

如果本机端口占用，可使用本机 `28689`，并相应执行 `python scripts/admin.py status --port 28689`，扩展也填写 `28689`。业务域名不转发管理端口。

会话加密持久化需要相同的数据目录与 `MUSE2API_SESSION_KEY`。不要为排障覆盖旧密钥或清空运行目录。重新授权前确认没有在途 Chat 或媒体调用；重启后的未完成媒体是 `unknown`，不重新提交生成。

需要迁移、回退或中转站配置时，读取当前仓库对应文档，核对实际版本和路径。Skill 安装本身不授权部署、发布或更改原生产配置。
